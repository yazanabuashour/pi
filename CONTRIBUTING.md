# Contribute to pi

Keep changes focused on reusable Pi resources and delivery. Personal settings,
credentials, private prompts, transcripts, and generated state stay outside this
repository. Preserve third-party notices.

Follow [development and validation](docs/development.md), including required local
integration checks. Record unavailable gates. In the change description, state
the user-visible outcome, checks run, and compatibility or lifecycle changes.

Do not modify live environments or publish releases as part of a contribution.
Report vulnerabilities through the [security policy](SECURITY.md), not public issues.
